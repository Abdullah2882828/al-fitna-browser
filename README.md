# 🌟 مشروع "الفطنة" (Al-Fitna)

> **متصفح مصغّر ينقل مشاريع الكود من محادثات الذكاء الاصطناعي (DeepSeek, ChatGPT, Claude, Gemini...) إلى ملفات حقيقية ويرفعها مباشرة إلى GitHub.**

---

## 💡 فكرة المشروع
تمنع مواقع الذكاء الاصطناعي العالمية تضمينها داخل تطبيقات الويب لحماية أمان المستخدمين. بدلاً من محاولة تجاوز ذلك أو استخدام واجهات وهمية، تعتمد **الفطنة** على حل أصيل:
**إشارة مرجعية سحّابة (Bookmarklet)** تعمل داخل Chrome على صفحة المحادثة مباشرة، تقرأ كتل الأكواد بدقة، ترتبها، وترسلها إلى نافذة الفطنة لتنظيم الملفات ثم رفعها إلى GitHub بـ Commit واحد متكامل.

```
Chrome (صفحة الذكاء الاصطناعي) 
  ↓ يشغّل المستخدم إشارة "fitna"
لوحة السحّاب (Shadow DOM)
  ↓ يختار الكتل ويضغط «إرسال للفطنة»
تطبيق الفطنة (مراجعة الملفات، فحص الأسرار، تنزيل ZIP)
  ↓
الرفع المباشر إلى GitHub (Git Data API)
```

---

## 🚀 التشغيل المحلي والتطوير

### المتطلبات:
- Node.js (الإصدار 18 أو أحدث)
- متصفح حديث (Chrome, Edge, Firefox)

### أوامر البدء:
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build
```

## 📱 النشر على GitHub Pages مباشرة من الهاتف (بدون حاسوب!)

يمكنك نشر الفطنة على استضافة GitHub Pages المجانية في 3 دقائق من هاتفك المحمول عبر متصفح Chrome:

1. **إنشاء مستودع جديد في GitHub:**
   - افتح موقع [github.com/new](https://github.com/new) من متصفح هاتفك وسجّل دخولك.
   - سمّ المستودع باسم: `al-fitna`، واجعله **Public (عام)**.
2. **رفع ملفات المشروع:**
   - يمكنك تنزيل ملفات المشروع من الفطنة عبر زر **ZIP**، أو رفعها من مدير الملفات في GitHub بالضغط على **Add file** ← **Upload files**.
3. **تفعيل استضافة GitHub Pages:**
   - ادخل على إعدادات المستودع: **Settings** ← **Pages**.
   - تحت قسم **Build and deployment**، اختر المصدر **Deploy from a branch**.
   - اختر الفرع `main` والمجلد `/ (root)` أو مجلد `/docs` ثم اضغط **Save**.
   - خلال دقيقة واحدة، سيصبح رابط الفطنة جاهزاً ويعمل أونلاين:
     `https://<username>.github.io/al-fitna/`

## 🔖 دليل تثبيت سحّاب الفطنة في Chrome على أندرويد

لأن متصفح Chrome للهواتف لا يدعم ملحقات الويب التقليدية، تُستخدم الإشارات المرجعية الذكية (Bookmarklets) كأسرع وأخف أداة لسحب الأكواد:

1. **افتح الفطنة من رابطها المنشور.**
2. في شاشة **📥 سحّاب**، اضغط الزر الأزرق **«نسخ كود السحّاب»**.
3. في Chrome، اضغط زر القائمة الثلاثية (`⋮`) ثم علامة النجمة (`⭐`) لحفظ الصفحة كإشارة مرجعية.
4. ادخل إلى: `⋮` ← **الإشارات المرجعية (Bookmarks)** ← اضغط مطولاً على الإشارة التي حفظتها ← **تعديل (Edit)**:
   - الاسم: اكتب `fitna` (بحروف صغيرة).
   - العنوان (URL): امسح الرابط القديم، والصق الكود الذي نسخته (يبدأ بـ `javascript:`).
   - اضغط حفظ.
5. **طريقة الاستخدام:**
   - افتح أي محادثة كود في DeepSeek أو ChatGPT.
   - اضغط على شريط عنوان المتصفح، واكتب `fitna`.
   - ستظهر لك الإشارة المرجعية وبجانبها أيقونة النجمة ⭐، اضغط عليها.
   - ستظهر لوحة السحّاب فوراً أسفل الشاشة، اختر الملفات واضغط **«📤 إرسال للفطنة»**!

## 🔒 الأمان وفاحص الأسرار (Secret Scanner)

- **بدون خوادم وسيطة:** جميع طلبات GitHub تتجه مباشرة من متصفحك إلى `https://api.github.com`.
- **تشفير محلي:** يتم تشفير رمز الوصول الشخصي (PAT) داخل متصفحك بخوارزمية `AES-GCM` باستخدام تقنية `WebCrypto`.
- **فاحص الأسرار التلقائي:** يفحص الكود تلقائياً قبل الرفع لأي مستودع بحثاً عن مفاتيح API شائعة (OpenAI, Google Gemini, AWS, SSH Keys, .env) ويحذر المستخدم من رفعها إلى مستودع عام.
- **قفل PIN:** يمكنك تعيين رمز سري من 4 أرقام لقفل واجهة التطبيق ومنع العبث بمشاريعك.

## 🧪 الفحص الذاتي الشامل (Self-Test)

يحتوي التطبيق في شاشة الإعدادات على وحدة اختبار ذاتية مدمجة تفحص تلقائياً:
1. ترميز وفك ضغط الحمولات السريعة (F0 غير مضغوط و F1 مضغوط بـ Gzip).
2. استنتاج أسماء الملفات وتفكيك شجرة ASCII.
3. تأمين وتطهير المسارات لمنع أي محاولات اختراق أو مسارات خبيثة (`../../etc/passwd`).
4. سلامة كود السحّاب البرمجي وتوليده في سطر واحد صالح.
